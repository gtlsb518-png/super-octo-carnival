# 시작하기 (윈도우)

## 준비물

- **파이썬 3.11 이상** — 없으면 [python.org](https://www.python.org/downloads/) 에서
  설치하세요. 설치할 때 **"Add Python to PATH"** 를 꼭 체크해야 합니다.
- **캡컷 데스크톱** (윈도우판)
- **Anthropic API 키** — [console.anthropic.com](https://console.anthropic.com) 에서 발급

---

## 1. 설치

압축 푼 폴더에서 **`설치.bat` 더블클릭.**

필요한 것들을 알아서 깔고 환경 점검까지 해줍니다. 몇 분 걸립니다.

## 2. API 키 등록

명령 프롬프트(cmd)를 열고:

```
setx ANTHROPIC_API_KEY "sk-ant-..."
```

**cmd 를 껐다 다시 켜야 적용됩니다.**

## 3. 실행

**`실행.bat` 위에 영상 파일을 끌어다 놓으세요.** 끝입니다.

또는 `실행.bat` 을 더블클릭하고, 창에 영상 파일을 끌어다 놓고 엔터.

```
영상: 1920x1080 @ 30.00fps, 612.0초
무음 구간 분석 중...
컷: 84개 구간, 486.2초 (원본 대비 125.8초 단축, 21%)
받아쓰기 중 (whisper large-v3)...
  처음이면 모델 약 3GB 를 내려받습니다. 시간이 걸립니다.
  CPU 로 돌리면 영상 길이의 1~3배쯤 걸립니다 (영상 10분 → 대략 10~31분)
받아쓰기: 213줄
효과음: 12개 사용 가능
큐시트 생성 중 (claude-opus-5, 밀도 normal)...
캡컷 초안 생성 중: ...\내영상_예능

완료: ...\내영상_예능
```

**캡컷을 열면 `내영상_예능` 프로젝트가 있습니다.**
목록에 안 보이면 아무 프로젝트나 열었다 나오거나 캡컷을 재시작하세요.

> **첫 실행은 오래 걸립니다.** Whisper 모델 3GB 다운로드 + 받아쓰기 때문입니다.
> 빨리 한번 보고 싶으면 cmd 에서:
> `python -m yeneung run "영상.mp4" --whisper-model small`

---

## 마음에 안 들면

캡컷에서 그냥 고치시면 됩니다. 자막·효과음·줌이 전부 **따로따로 클립**이라
하나씩 잡고 수정할 수 있습니다.

도구 쪽에서 바꾸고 싶으면 cmd 에서 옵션을 붙여 다시 돌리세요.

```
cd 압축푼폴더\yeneung-capcut

REM 자막이 너무 많다
python -m yeneung run "영상.mp4" --density low

REM 자막 문체가 안 맞는다
python -m yeneung run "영상.mp4" --tone "차분한 브이로그"

REM 컷이 과하다
python -m yeneung run "영상.mp4" --no-cut

REM 전환이 거슬린다
python -m yeneung run "영상.mp4" --no-transitions
```

받아쓰기 결과는 캐시되므로 **두 번째부터는 빠릅니다.**
자막만 다시 만들려면 `--refresh-cuesheet` 를 붙이세요.

더 세밀한 조정은 `README.md` 를 보세요. 자막 크기·색·위치는
`config.example.toml` 을 `config.toml` 로 복사해서 고치면 됩니다.

---

## 안 될 때

| 증상 | 해결 |
|---|---|
| `python` 을 못 찾음 | 파이썬 재설치, "Add Python to PATH" 체크 |
| API 키 오류 | `setx` 후 **cmd 를 껐다 켰는지** 확인 |
| 캡컷 초안 폴더를 못 찾음 | `python -m yeneung run "영상.mp4" --draft-dir "경로"` |
| 프로젝트가 목록에 없음 | 아무 프로젝트나 열었다 나오기 / 캡컷 재시작 |
| 한글이 □□□ | 자막 하나 클릭 → 폰트를 한글 폰트로 → "모두 적용" |
| 자막이 화면 밖 | `config.toml` 의 `position_y` 부호를 뒤집으세요 |

**뭔가 잘못됐는데 원인을 모르겠으면** 이걸 돌려보세요. 받아쓰기도 API 도
안 쓰고 샘플 자막만 넣은 프로젝트를 만듭니다.

```
python -m yeneung demo "영상.mp4"
```

이건 되는데 `실행.bat` 이 안 되면 받아쓰기나 API 쪽 문제이고,
이것부터 안 되면 캡컷 쪽 문제입니다. 구분해서 알려주시면 빨리 고칩니다.

## 문제 알려주실 때

실행한 것과 나온 메시지를 **그대로** 붙여 주세요. 화면에 뜬 빨간 글씨나
`[실패]` 아래 내용이면 충분합니다.
