# 시작하기 (윈도우)

처음 테스트하실 때 순서대로 따라 하시면 됩니다.
**1~3단계까지만 해도 캡컷에서 열리는지 확인할 수 있습니다.** (API 키 불필요)

---

## 1. 파이썬 설치 확인

명령 프롬프트(cmd)를 열고:

```
python --version
```

`3.11` 이상이면 됩니다. 없거나 낮으면 [python.org](https://www.python.org/downloads/)
에서 설치하세요. 설치할 때 **"Add Python to PATH"** 를 꼭 체크하세요.

## 2. 설치

압축을 푼 폴더에서 cmd 를 열고:

```
cd 압축푼폴더\yeneung-capcut
pip install pycapcut numpy pymediainfo av
```

> 여기서는 캡컷 확인에 필요한 것만 깝니다. 받아쓰기(faster-whisper)와
> Claude(anthropic)는 4단계에서 깔아도 됩니다. 용량이 커서 나눠 놨습니다.

환경 점검:

```
python -m yeneung doctor
```

캡컷 초안 폴더를 찾았는지 보세요. 못 찾으면 아래처럼 직접 알려주면 됩니다.

```
%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft
```

## 3. 캡컷에서 열리는지 확인 (제일 중요)

**아무 영상이나** 하나 잡고:

```
python -m yeneung demo "C:\경로\내영상.mp4"
```

받아쓰기도 Claude 도 안 씁니다. 샘플 자막·효과음·줌·전환을 넣은
프로젝트만 만듭니다.

이렇게 나오면 성공입니다:

```
완료: ...\내영상_데모
  클립 7개 · 예능자막 7개 · 효과음 7개 · 줌 2개 · 화면효과 2개 · 전환 2개
```

**캡컷을 열어서 `내영상_데모` 프로젝트를 확인하세요.**
목록에 안 보이면 아무 프로젝트나 열었다 나오거나 캡컷을 재시작하면 갱신됩니다.

### 여기서 확인해 주실 것

데모 자막은 **자기가 무엇을 검사 중인지 스스로 말합니다.** 순서대로 뜹니다.

```
① 맨위 top      ② 중상 upper    ③ 한가운데 center
④ 중하 lower    ⑤ 기본위치 강조  ⑥ 타자기 효과
⑦ 흔들림 효과   ⑧ 반짝 효과
```

- [ ] 프로젝트가 목록에 뜨고 오류 없이 열리는가
- [ ] **①②③④ 가 화면 위에서 아래 순서로 뜨는가**
      (거꾸로 뜨면 좌표 부호 문제입니다. 꼭 알려주세요)
- [ ] 한글이 □□□ 로 깨지지 않는가 (깨지면 폰트 문제 — 아래 참고)
- [ ] 자막마다 등장 방식이 다른가 (①툭 ②서서히 ③아래서 ⑥한글자씩 ⑦흔들림)
- [ ] ⑤가 가장 크고 붉은 계열인가 (스타일별 크기·색 확인)
- [ ] 영상이 여러 클립으로 잘려 있는가
- [ ] 효과음이 자막 뜰 때 같이 들리는가
- [ ] 줌 클립에서 화면이 확대됐다 돌아오는가
- [ ] 컷 경계에 전환(디졸브 등)이 걸려 있는가

이상한 항목의 **번호만 알려주셔도** 어디를 고쳐야 할지 바로 압니다.

**한글이 □□□ 로 보이면:** 자막 하나를 클릭 → 폰트를 한글 폰트로 변경 →
"모두 적용". 캡컷 기본 폰트가 한글을 지원하지 않는 경우입니다.

## 4. 실제로 돌려보기

3단계가 잘 됐으면 나머지를 설치합니다.

```
pip install faster-whisper anthropic
```

Anthropic API 키를 환경변수로 등록합니다. cmd 에서:

```
setx ANTHROPIC_API_KEY "sk-ant-..."
```

**cmd 를 껐다 다시 켜야** 적용됩니다. 그다음:

```
python -m yeneung run "C:\경로\내영상.mp4"
```

처음 실행하면 Whisper 모델(약 3GB)을 내려받습니다. 시간이 걸립니다.
빨리 확인만 하고 싶으면:

```
python -m yeneung run "C:\경로\내영상.mp4" --whisper-model small
```

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `python` 을 못 찾음 | 파이썬 설치 시 "Add Python to PATH" 체크 안 함. 재설치 |
| `pip` 을 못 찾음 | `python -m pip install ...` 로 실행 |
| 캡컷 초안 폴더를 못 찾음 | `--draft-dir "경로"` 로 직접 지정 |
| 프로젝트가 목록에 없음 | 아무 프로젝트나 열었다 나오기 / 캡컷 재시작 |
| 한글이 □□□ | 자막 폰트를 한글 폰트로 바꾸고 "모두 적용" |
| 자막이 화면 밖 | `config.toml` 의 `position_y` 부호를 뒤집으세요 |
| 경로에 공백이 있어 에러 | 경로를 큰따옴표로 감싸세요 |

## 문제가 생기면

무엇을 실행했고 어떤 메시지가 나왔는지 그대로 알려주세요.
`demo` 는 되는데 `run` 이 안 되면 받아쓰기나 큐시트 쪽 문제이고,
`demo` 부터 안 되면 캡컷 호환성 문제입니다. 이 구분이 있으면 빨리 고칩니다.
