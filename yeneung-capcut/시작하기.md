# 시작하기 (윈도우)

## 1. 실행

압축을 풀고, **`실행.bat` 위에 영상 파일을 끌어다 놓으세요.** 끝입니다.

또는 `실행.bat` 을 더블클릭하고, 창에 영상 파일을 끌어다 놓고 엔터.

처음 한 번은 필요한 것들을 **알아서 설치**합니다. 몇 분 걸립니다.
다음부터는 바로 실행됩니다.

> 파이썬만 없으면 자동으로 못 깝니다. 그때는 안내와 함께 내려받는 페이지가
> 열립니다. 설치 화면 맨 아래 **"Add Python to PATH"** 를 꼭 체크하세요.
> 캡컷 데스크톱(윈도우판)은 미리 깔려 있어야 합니다.

```
============================================
  처음 실행 - 필요한 것을 자동으로 설치합니다
============================================
파이썬을 찾았습니다. 전용 실행 환경을 만듭니다...
라이브러리를 내려받습니다. 인터넷 속도에 따라 5~20분 걸립니다...
기본 효과음을 만듭니다...

영상: 1920x1080 @ 30.00fps, 612.0초
무음 구간 분석 중...
컷: 84개 구간, 486.2초 (원본 대비 125.8초 단축, 21%)
받아쓰기 중 (whisper large-v3)...
  처음이면 모델 약 3GB 를 내려받습니다. 시간이 걸립니다.
받아쓰기: 213줄
효과음: 12개 사용 가능
큐시트 생성 중 (규칙 기반, API 안 씀, 밀도 normal)...
큐시트: 자막 41개 · 효과음 38개 · 줌 12개 · 화면효과 5개 · 전환 4개
캡컷 초안 생성 중: ...\내영상_예능

완료: ...\내영상_예능
```

**캡컷을 열면 `내영상_예능` 프로젝트가 있습니다.**
목록에 안 보이면 아무 프로젝트나 열었다 나오거나 캡컷을 재시작하세요.

> **첫 실행은 오래 걸립니다.** Whisper 받아쓰기 모델 3GB 다운로드 때문입니다.
> 빨리 한번 보고 싶으면 아래 "옵션 붙여 다시 돌리기" 의
> `--whisper-model small` 을 쓰세요.

## 2. 마음에 안 들면

캡컷에서 그냥 고치시면 됩니다. 자막·효과음·줌이 전부 **따로따로 클립**이라
하나씩 잡고 수정할 수 있습니다.

### 옵션 붙여 다시 돌리기

폴더 주소창에 `cmd` 를 치고 엔터하면 그 폴더에서 명령 프롬프트가 열립니다.

```
REM 자막이 너무 많다 / 적다
.venv\Scripts\python -m yeneung run "영상.mp4" --density low
.venv\Scripts\python -m yeneung run "영상.mp4" --density high

REM 컷이 과하다
.venv\Scripts\python -m yeneung run "영상.mp4" --no-cut

REM 전환이 거슬린다
.venv\Scripts\python -m yeneung run "영상.mp4" --no-transitions

REM 내 효과음 폴더를 쓰고 싶다
.venv\Scripts\python -m yeneung run "영상.mp4" --sfx-dir "D:\내효과음"

REM 자막을 내가 직접 써서 넣고 싶다
.venv\Scripts\python -m yeneung run "영상.mp4" --cuesheet "내큐시트.json"
```

받아쓰기 결과는 캐시되므로 **두 번째부터는 빠릅니다.**
자막만 다시 만들려면 `--refresh-cuesheet` 를 붙이세요.

자막 크기·색·위치는 `config.example.toml` 을 `config.toml` 로 복사해서
고치면 됩니다.

## 3. 자막을 더 잘 뽑고 싶으면 (선택)

기본은 **API 를 쓰지 않습니다.** 대사에서 "대박", "됐다", "어?", 웃음,
정적 같은 **글자로 알 수 있는 신호**를 찾아 자막을 붙입니다.
돈이 안 들고 결과가 항상 같지만, 장면의 맥락은 못 읽습니다.

맥락까지 읽게 하려면 Anthropic API 키를 등록하세요. 그러면 자동으로
그쪽을 씁니다.

```
.venv\Scripts\python -m pip install -r requirements-api.txt
setx ANTHROPIC_API_KEY "sk-ant-..."
```

**cmd 를 껐다 다시 켜야 적용됩니다.** 키가 있어도 API 를 안 쓰고 싶으면
`--no-api` 를 붙이세요.

## 안 될 때

**`점검.bat`** 을 실행하세요. 환경을 점검하고, 원하면 처음부터 다시 깝니다.

| 증상 | 해결 |
|---|---|
| `python` 을 못 찾음 | 파이썬 재설치, "Add Python to PATH" 체크 |
| 설치가 중간에 실패 | `점검.bat` → 다시 설치 |
| 캡컷 초안 폴더를 못 찾음 | `... run "영상.mp4" --draft-dir "경로"` |
| 프로젝트가 목록에 없음 | 아무 프로젝트나 열었다 나오기 / 캡컷 재시작 |
| 한글이 □□□ | 자막 하나 클릭 → 폰트를 한글 폰트로 → "모두 적용" |
| 자막이 화면 밖 | `config.toml` 의 `position_y` 부호를 뒤집으세요 |

**원인을 모르겠으면** 이걸 돌려보세요. 받아쓰기도 API 도 안 쓰고
샘플 자막만 넣은 프로젝트를 만듭니다.

```
.venv\Scripts\python -m yeneung demo "영상.mp4"
```

이건 되는데 `실행.bat` 이 안 되면 받아쓰기 쪽 문제이고,
이것부터 안 되면 캡컷 쪽 문제입니다. 구분해서 알려주시면 빨리 고칩니다.

## 문제 알려주실 때

실행한 것과 나온 메시지를 **그대로** 붙여 주세요. 화면에 뜬 빨간 글씨나
`[실패]` 아래 내용이면 충분합니다.
