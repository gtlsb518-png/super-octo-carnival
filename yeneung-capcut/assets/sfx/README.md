# 효과음 폴더

여기에 효과음이 들어갑니다. **직접 준비할 필요 없습니다** — 처음 실행하면
기본 팩이 자동으로 생성됩니다.

```
python -m yeneung sfx generate     # 직접 만들고 싶을 때
python -m yeneung sfx              # 목록 확인
```

효과음은 다운로드가 아니라 **합성해서 만듭니다**. 저작권 문제가 없고
네트워크도 필요 없습니다. 생성되는 12가지:

| 이름 | 소리 |
|---|---|
| `ding` | 띵! 정답, 깨달음, 포인트 강조 |
| `correct` | 딩동댕. 정답, 성공, 통과 |
| `error` | 삐-삐-. 오답, 탈락 |
| `boing` | 뿅! 엉뚱한 행동, 귀여운 실수 |
| `pop` | 뾱. 자막 등장, 가벼운 포인트 |
| `swoosh` | 슝. 화면 전환, 시선 이동 |
| `drum` | 둥! 결정적 순간, 반전 직전 |
| `tension` | 두구두구. 결과 발표 직전 |
| `fail` | 뿌우-. 실수, 좌절, 계획 무산 |
| `sparkle` | 반짝. 자화자찬, 뿌듯한 순간 |
| `crickets` | 귀뚜라미. 정적, 썰렁함 |
| `record_scratch` | 찌익. 분위기 급정지, 예상 빗나감 |

## 소리 바꾸기

마음에 안 드는 소리는 **같은 이름의 파일로 덮어쓰면** 그대로 대체됩니다.
`sfx generate` 는 이미 있는 파일을 건드리지 않습니다.

```
assets/sfx/ding.wav   ← 여기에 원하는 파일을 덮어쓰기
```

전부 다시 만들려면 `sfx generate --force`.

## 효과음 추가하기

새 소리를 넣으려면 파일을 두고 `manifest.json` 에 항목을 추가하세요.

```json
{
  "laugh": { "file": "laugh.wav", "desc": "방청객 웃음소리. 확실한 웃음 포인트" }
}
```

`desc` 는 Claude 가 **언제 이 효과음을 쓸지** 판단하는 유일한 근거입니다.
소리의 생김새와 쓰임새를 같이 적어주세요.

- 좋은 예: `"찌익. 분위기가 급정지하는 순간, 예상 빗나감"`
- 나쁜 예: `"효과음 3번"`

## 없는 것

**방청객 웃음소리**는 합성으로 흉내 낼 수 없어 빠져 있습니다. 예능에서 꽤
중요한 소리라 필요하시면 직접 구해서 `laugh.wav` 로 넣고 위처럼 매니페스트에
설명을 적어주세요. 상업적으로 쓸 영상이면 라이선스를 확인하시기 바랍니다.
