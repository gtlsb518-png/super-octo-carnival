# 효과음 폴더

여기에 효과음 파일(`.wav`, `.mp3`, `.m4a`, `.aac`, `.flac`, `.ogg`)을 넣으세요.

## 설정 방법

`manifest.example.json` 을 `manifest.json` 으로 복사하고, 실제 넣은 파일에 맞게
고치면 됩니다.

```json
{
  "ding": { "file": "ding.wav", "desc": "띵! 정답, 깨달음, 포인트 강조" }
}
```

`manifest.json` 이 없으면 폴더 안의 오디오 파일을 **파일 이름 그대로** 자동
등록합니다. 다만 이 경우 설명이 없어서 Claude 가 언제 써야 할지 알기 어려우니,
매니페스트를 쓰는 편이 결과가 훨씬 좋습니다.

## `desc` 가 중요한 이유

`desc` 는 Claude 가 **"이 효과음을 언제 깔지"** 판단하는 유일한 근거입니다.
소리의 생김새와 쓰임새를 같이 적어주세요.

- 좋은 예: `"찌익. 분위기가 급정지하는 순간, 예상 빗나감"`
- 나쁜 예: `"효과음 3번"`, `"sfx_03"`

## 확인

```
yeneung sfx
```

## 저작권

효과음 파일은 이 저장소에 포함되어 있지 않습니다. 직접 준비하세요.
상업적으로 쓸 영상이라면 라이선스를 반드시 확인하시기 바랍니다.
