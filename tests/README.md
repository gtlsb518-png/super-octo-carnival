# 자막 기준 (사용자 확정 사항)

자막 관련 코드를 고칠 때는 **반드시** 아래를 먼저 돌린다.

```bash
python3 tests/자막_기준_테스트.py     # 사용자가 만든 완성 자막 27줄 + 개별 규칙 6종
```

## 확정된 기준

### 길이
- 한 줄 **12자** 기본 (최대 17자). 사용자 완성본 27줄 실측: 평균 10.5자 / 최소 2자 / 최대 16자
- 한 조각은 화면에 **최소 0.3초** 유지

### 끊는 자리
| 규칙 | 예 |
|---|---|
| 문장부호에서 끊음 | `무너졌어?` / `놉.` |
| 다음이 한 문장이면 먼저 끊음 | `우리 반이야` / `오케이?` |
| `~할 때 / ~한 뒤 / ~한 다음` 뒤에서 끊음 | `멘탈 흔들릴 때` / `같이 있는 게` |
| 앞말이 꾸미는 형태일 때만 절로 봄 | `3시간 동안 팔에` (동안 뒤에서 안 끊음) |
| 의존명사 앞에서 안 끊음 | `하는 게` (하는 / 게 ✗) |
| 꾸미는 말 뒤에서 안 끊음 | `전 세계`, `같은 생각` |
| 뒷말을 꾸미는 형태 앞에서 끊음 | `그래서 오늘` / `하이닉스 물린 사람들` |
| 쉼표는 줄 끝에 | `하고 있지,` / `아무 종목이나` |
| 단, 남은 문장이 한 줄에 들어가면 안 끊음 | `독보적이라던 기술, 무너졌어?` |
| 다음 말까지 넣으면 목표를 넘길 때 지금 끊음 | `오늘 왜 알테오젠의` / `불이 켜졌는지,` |
| 꾸미는 말+명사가 딱 한 줄이면 그 앞에서 끊음 | `5분 주사로` / `바꿔주는 기술이야.` |
| 꼬리가 한두 글자면 앞 조각과 다시 나눔 | `아무 종목이나` / `하는 게 아니야` |

### 시간
- 영상 클립 길이 = 그 위 자막 길이 **정확히 일치** (클립 경계를 넘지 않음)
- 자막 경계는 **30fps 프레임 격자**에 스냅
- 자막은 **다음 말이 시작되기 직전**까지 유지. 길게 끄는 말은 **끝나기 전에 안 끊음**

### 자료화면 배치 (캡컷 표시값)
- 이미지: 크기 **79** / X **0** / Y **-892**
- 영상: 크기 **87** / X **0** / Y **-1022**

### 기본 설정
노이즈 임계값 **자동** / 최소 무음 **0.3s** / 앞 여유 **+10ms** / 뒤 여유 **-10ms** /
자막 글자 수 **12** / 자료화면 랜덤 효과 **켜짐 0.5초**
