========================================
 CapCut Agent - 사용법
========================================

무음 자동 컷편집 + 한국어 자막 + 자료화면 자동 삽입 도구입니다.
CapCut(캡컷) 8.7.0 에서 열리는 프로젝트(draft)를 자동으로 만들어 줍니다.


■ 설치 (처음 한 번만)
----------------------------------------
1) 이 압축 폴더를 원하는 위치에 통째로 풉니다.
2) "설치및실행.bat" 을 더블클릭합니다.
   - 처음 실행이면 Python 과 ffmpeg 를 자동으로 내려받습니다.
     (인터넷 연결 필요, 관리자 권한은 필요 없음)
     이 폴더 안 runtime\ 폴더에만 설치되고 컴퓨터에는 아무것도 안 건드립니다.
   - 다 준비되면 브라우저가 자동으로 열립니다. (안 열리면 http://localhost:8765)

* 자막(음성인식) 기능:
   자막 옵션을 켜고 실행하면 필요한 것이 자동으로 설치됩니다.
   (용량이 커서 처음 한 번은 몇 분 걸립니다. 인터넷 연결 필요)
   미리 받아두고 싶으면 "자막기능_추가설치.bat" 을 실행해도 됩니다.
   자막을 안 쓰면 설치 없이 컷편집 / 파일 삽입은 바로 됩니다.


■ 기본 사용
----------------------------------------
1) 영상 파일 경로를 입력하거나 "찾아보기" 로 고릅니다.
2) 무음 감지 설정 / 화면 비율(숏츠·가로) / 자막 옵션을 정합니다.
3) "▶ draft 생성" 을 누릅니다.
4) 완료되면 "CapCut에 바로 적용" 또는 "Draft 다운로드(zip)" 를 씁니다.
   - 바로 적용이 안 되면 zip 을 풀어서 아래 폴더에 복사하세요:
     %USERPROFILE%\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft\
   - 복사 후 CapCut 을 재시작하면 프로젝트 목록에 나타납니다.


■ 자막
----------------------------------------
· 영상 클립을 하나씩 개별 인식해서, 모든 클립에 자막이 빠짐없이 들어갑니다.
  (같은 문장을 여러 번 찍은 엔지컷도 각각 자기가 말한 내용으로 자막이 붙어
   나중에 좋은 테이크를 골라내기 편합니다.)
· 자막은 한 줄 9자 안팎(최대 14자)이고, 화면에서 조절할 수 있습니다.
· 문장부호(. ? !)와 한국어 연결어미(-는데, -면, -니까, -까지 등)에서
  자연스럽게 끊어집니다.
· 자막바는 클립 끝까지 유지되어 중간에 사라지지 않습니다.
  영상 클립 하나 위의 자막들은 클립 시작~끝을 빈틈없이 채웁니다.
  (= 영상 클립 길이와 그 위 자막 길이가 정확히 일치. 실행 로그의
   "영상 클립 = 자막 길이 일치: N/N개" 로 확인할 수 있습니다)
· 마침표는 자동으로 지웁니다. (3.7% 같은 소수점은 그대로 둡니다)
· 잡음 구간에서 나오는 엉뚱한 영어(환각)와 이모지·특수문자는 걸러냅니다.
· 말소리가 없는 클립에는 "..." 자막이 들어갑니다.

* 대본을 넣으면 정확도가 올라갑니다.
  대본 입력칸에 붙여넣거나 .txt 파일을 불러오면, 인식 결과를 대본과 대조해
  오탈자를 고칩니다. (대본에 없는 애드립은 인식된 그대로 둡니다.)
  실행 로그에 "대본 참고 철자 교정 N개 적용" 이 표시됩니다.


■ 자료화면 (영상·이미지 자동 삽입)
----------------------------------------
"추가 파일" 에서 "파일 여러 개 선택" 으로 영상·이미지를 고르면
다운로드(저장) 시간 순으로 자동 정렬되어 배치됩니다.
 - 파일에 마우스를 올리면 어떤 이미지인지 미리보기가 뜹니다.
 - 파일마다 체크박스로 배경제거를 개별 선택할 수 있습니다.
   (배경제거 + 흰색 발광 획, 획 크기 조절 가능)
 - 크기·위치를 하나로 통일해서 넣습니다.
 - "모든 자료화면에 랜덤 효과" 를 켜면 자료화면마다 등장 효과가 들어갑니다.
   (메인 컷편집 영상에는 효과가 들어가지 않습니다)

 · 통합: 그대로 "▶ draft 생성" 을 누르면 컷편집 영상 뒤에 이어붙습니다.
 · 별도: "선택 파일로만 새 프로젝트" 를 누르면 고른 파일들만으로 만듭니다.


■ 제목 · 날짜
----------------------------------------
· 상단 제목: 첫 줄은 빨강, 나머지 줄은 흰색으로 들어갑니다 (최대 3줄).
· 하단 날짜: "항상 오늘 날짜" 를 켜두면 실행할 때마다 오늘 날짜(MM-DD)로
  자동 입력됩니다. 체크를 풀면 직접 입력할 수 있습니다.


■ 문제 해결
----------------------------------------
· 설치가 실패하면: 인터넷/방화벽 문제일 수 있습니다. 다른 네트워크에서
  "설치및실행.bat" 을 한 번만 실행하면 runtime\ 이 만들어져 이후엔 오프라인도 됩니다.
· 실행 중 오류가 나면 이 폴더에 error_log.txt 가 생깁니다.
· 다시 처음부터 설치하고 싶으면: runtime\ 폴더를 지우고 다시 실행하세요.
· 자막 인식은 클립 수만큼 시간이 걸립니다. 진행 상황이 로그에 표시됩니다.
