========================================
 CapCut Agent - 사용법
========================================

무음 자동 컷편집 + 한국어 자막 + 자료화면 자동 삽입 도구입니다.
CapCut(캡컷) 8.7.0 에서 열리는 프로젝트(draft)를 자동으로 만들어 줍니다.


■ 설치 (처음 한 번만)
----------------------------------------
1) 이 압축 폴더를 원하는 위치에 통째로 풉니다.
2) "전체설치.bat" 을 더블클릭합니다.  ← 필요한 걸 한 번에 다 깝니다
     · Python + ffmpeg + 서버
     · 자막(음성인식) + 음성 모델 (약 3GB)
     · 배경제거 + 모델 (약 176MB)
   인터넷만 되면 되고, 관리자 권한은 필요 없습니다.
   이 폴더 안 runtime\ 폴더에만 설치되고 컴퓨터에는 아무것도 안 건드립니다.
   모델까지 미리 받아두므로, 처음 자막을 돌릴 때 멈춰 있는 일이 없습니다.
   (다운로드가 커서 시간이 걸립니다. 켜두고 다른 일 하셔도 됩니다)
   ※ 이미 깔린 건 건너뛰므로 언제든 다시 눌러도 됩니다.
3) 그 다음부터는 "설치및실행.bat" 으로 실행합니다.
   다 준비되면 브라우저가 자동으로 열립니다. (안 열리면 http://localhost:8765)

* "전체설치.bat" 을 안 돌려도 동작은 합니다.
   자막·배경제거를 처음 쓰는 순간 프로그램이 알아서 설치합니다.
   다만 그때 몇 분 기다리게 되니, 미리 받아두는 쪽을 권합니다.
   ("자막기능_추가설치.bat" 은 예전 이름이고, 눌러도 똑같이 전부 설치됩니다)
   자막을 안 쓰면 설치 없이 컷편집 / 파일 삽입은 바로 됩니다.


■ 기본 사용
----------------------------------------
1) 영상 파일 경로를 입력하거나 "찾아보기" 로 고릅니다.
2) 무음 감지 설정 / 화면 비율(숏츠·가로) / 자막 옵션을 정합니다.
3) "▶ draft 생성" 을 누릅니다.
4) 완료되면 "CapCut에 바로 적용" 또는 "Draft 다운로드(zip)" 를 씁니다.
   - 바로 적용이 안 되면 zip 을 풀어서 아래 폴더에 복사하세요:
     %USERPROFILE%\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft\
   - 복사 후 CapCut 을 재시작하면 프로젝트 목록에 나타납니다.


■ 타이트 컷 (손편집처럼 더 바짝 자르기)
----------------------------------------
· 노이즈 임계값 "자동"(기본)을 켜두면 영상마다 알맞은 값을 직접 재서 고릅니다.
  방 소음(에어컨·숨소리) 크기가 녹음마다 달라서, 고정 -40dB 로는 어떤 영상은
  무음이 하나도 안 잘립니다. 여러 기준으로 실제 재보고
  "말을 토막내기 직전의 가장 센 값" 을 고릅니다.
  실행 로그에 기준별 결과가 표로 나오니 확인하실 수 있습니다.
   예) -40dB → 무음 제거  1.7% / 클립   4개 / 짧은 조각  0.0% ✓
       -30dB → 무음 제거 22.2% / 클립  25개 / 짧은 조각  4.0% ✓
       -25dB → 무음 제거 79.7% / 클립 160개 / 짧은 조각 99.4% ✗ (말이 잘림)
  체크를 풀면 슬라이더 값을 그대로 씁니다.

· "최소 무음 길이" 기본값은 0.3초입니다. 이 값보다 짧은 공백은 안 잘립니다.
  0.1초까지 내리면 말 사이 아주 짧은 틈까지 잘라서 클립이 잘게 부서지고,
  그 짧은 조각에서 자막 인식이 엉뚱하게 나옵니다. 0.25~0.3초를 권합니다.
· "컷 여유" 로 클립 앞뒤를 조절합니다. (-면 더 깎고, +면 더 남깁니다)
   - 클립 앞 여유 : 기본 +30ms  (말 첫소리가 씹히지 않게 살짝 남김)
   - 클립 뒤 여유 : 기본 0ms    (말꼬리는 깎지 않음)
   - 더 남기는 쪽(+)은 잘라낸 무음 안에서만 늘어나고, 옆 클립은 침범하지 않습니다.
   - "짧은 클립 버리기": 정해준 길이보다 짧은 컷은 통째로 뺍니다.
     엔지컷을 남겨서 직접 고르실 거면 이건 꺼두세요.
· 너무 깎여서 클립이 사라질 상황이면 그 클립은 깎지 않습니다.

* 말이 씹힐 때 조정 순서
   1) 클립 앞 여유를 +30 → +60 → +100ms 로 올립니다 (가장 먼저 이것부터)
   2) 그래도 씹히면 노이즈 임계값을 -40dB → -45dB 로 (작은 소리도 말로 인정)
   3) 앞뒤가 너무 늘어지면 최소 무음 길이를 0.3 → 0.5초로 올립니다

* 더 타이트하게 붙이고 싶으면
   앞 여유 -150ms / 뒤 여유 -200ms 까지 내려보세요.

· "🔁 같은 말 반복(엔지컷) 정리" 를 켜면 같은 말을 연달아 여러 번 찍은 구간에서
  짧은 테이크만 자동으로 지웁니다.
   - 같은 말이 2번 이상 이어지고 + 정한 길이(기본 1.5초)보다 짧으면 → 삭제
   - 같은 말이라도 그보다 길면 → 전부 남깁니다 (좋은 테이크를 직접 고르시라고)
   - 한 묶음이 전부 짧으면 마지막 하나는 남깁니다 (내용이 통째로 없어지지 않게)
   - "삼성이" → "삼성이 주가" → "삼성이 주가 하락의 원인은" 처럼 하다 만 테이크도
     같은 말로 봅니다. "첫 번째 이유는" / "두 번째 이유는" 같이 앞이 다르면
     다른 말로 보고 건드리지 않습니다.
   - 말 내용으로 판단하므로 자막(음성인식)을 켜야 동작합니다.
   - 지운 클립은 실행 로그에 번호·길이·내용이 표시됩니다.


■ 자막
----------------------------------------
· 영상 클립을 하나씩 개별 인식해서, 모든 클립에 자막이 빠짐없이 들어갑니다.
  (같은 문장을 여러 번 찍은 엔지컷도 각각 자기가 말한 내용으로 자막이 붙어
   나중에 좋은 테이크를 골라내기 편합니다.)
· 자막은 한 줄 12자 안팎(최대 17자)이고, 화면에서 조절할 수 있습니다.
  (끊는 규칙은 9자든 12자든 같습니다. 짧게 쓰고 싶으면 슬라이더를 내리세요)
· 문장부호(. ? !)와 한국어 연결어미(-는데, -면, -니까, -까지 등)에서
  자연스럽게 끊어집니다. 한 덩어리인 말은 쪼개지 않습니다:
   - 의존명사 앞에서 안 끊음      ("하는 / 게" X → "하는 게" O)
   - 꾸미는 말 뒤에서 안 끊음     ("전 / 세계" X → "전 세계" O,
                                 "같은 / 생각" X → "같은 생각" O)
   - 뒤에 오는 말을 꾸미는 형태면 그 앞에서 끊음
                                 ("오늘 하이닉스 / 물린 사람들" X
                                  → "그래서 오늘 / 하이닉스 물린 사람들" O)
   - "~할 때 / ~한 뒤 / ~한 다음" 뒤에서 끊음
                                 ("흔들릴 때 같이 / 있는 게 우리" X
                                  → "멘탈 흔들릴 때 / 같이 있는 게 / 우리 반이야" O)
   - 앞말과 한 덩어리인 의존명사는 그 뒤에서 끊음 ("있는 게" 뒤)
   - 다음이 한 문장이면 먼저 끊어 따로 세움 ("우리 반이야" / "오케이?")
   - 쉼표는 조각 끝에 오게 함  ("있지, 아무 종목이나" X
                                → "하고 있지," / "아무 종목이나" O)
     ("좋아, 가자" 처럼 너무 짧으면 그냥 한 조각으로 둡니다)
   - 남은 문장이 한 줄에 다 들어가면 쉼표가 있어도 안 끊음
                                 ("독보적이라던 기술, 무너졌어?" 한 줄)
   - 다음 말까지 넣으면 목표 글자수를 넘길 때는 지금 끊음
                                 ("오늘 왜 알테오젠의" / "불이 켜졌는지,")
   - "꾸미는 말 + 명사"가 딱 한 줄이면 그 앞에서 끊음
                                 ("5분 주사로" / "바꿔주는 기술이야.")
   - 쉼표가 붙어버린 말은 나눠서 끊음 ("주주들,그동안" → "주주들," / "그동안")
   - 마지막에 한두 글자만 남으면 앞 조각과 다시 나눔
                                 ("아무 종목이나 하는 게 / 아니야" X
                                  → "아무 종목이나 / 하는 게 아니야" O)
· 자막바는 클립 끝까지 유지되어 중간에 사라지지 않습니다.
  영상 클립 하나 위의 자막들은 클립 시작~끝을 빈틈없이 채웁니다.
  (= 영상 클립 길이와 그 위 자막 길이가 정확히 일치. 실행 로그의
   "영상 클립 = 자막 길이 일치: N/N개" 로 확인할 수 있습니다)
· 자막 클립은 "다음 말이 시작되기 직전"까지 유지됩니다.
  말을 길게 끄는 경우("올랐는데~~~")에도 그 말이 끝나기 전에는 끊지 않습니다.
  (Whisper가 길게 끈 말의 끝과 다음 말의 시작을 겹쳐서 주는 일이 잦은데,
   그때 자막이 말 도중에 바뀌던 문제를 막습니다)
· 자막 경계도 영상과 같은 프레임 격자(30fps)에 딱 맞춥니다. 한 프레임도
  어긋나지 않아 캡컷에서 클립 끝과 자막 끝이 정확히 같은 자리에 섭니다.
· 마침표는 자동으로 지웁니다. (3.7% 같은 소수점은 그대로 둡니다)
· 잡음 구간에서 나오는 엉뚱한 영어(환각)와 이모지·특수문자는 걸러냅니다.
· 말소리가 없는 클립에는 "..." 자막이 들어갑니다.
· 짧은 클립에 말도 안 되는 분량이 인식되면(Whisper 환각) 실제 말할 수 있는
  만큼만 남깁니다. 0.07초짜리 자막이 우수수 지나가지 않습니다.
· 한 자막 조각은 최소 0.3초는 떠 있습니다. 클립이 짧으면 조각을 합칩니다.
· 같은 영어 단어가 제각각 인식되면(NVIDIA / Nvidia / MVDIIA) 가장 많이 나온
  표기로 통일합니다.
· 자막 끝에 남는 쉼표는 지우고, "두고,새" 처럼 붙은 쉼표는 띄웁니다.
· Whisper가 조용한 구간에 넣는 상투 문구("시청해주셔서 감사합니다",
  "구독과 좋아요" 등)는 실제 발화가 아니므로 걸러냅니다.
  ("감사합니다 여러분" 처럼 문장 속에 들어있는 건 그대로 둡니다)
· 같은 글자가 3번 이상 이어지는 인식 오류("오를때에에에")는 줄이고,
  같은 말이 3번 이상 이어지면("오늘 오늘 오늘") 한 번만 남깁니다.
· 알아볼 수 없는 덩어리("쎈쎼쎽쎵쎶쎱...")는 통째로 버립니다.
· "멘 탈 흔" 처럼 한 글자씩 흩어져 나온 인식은 말로 치지 않습니다.
· 한 글자짜리 영문("I", "E", "U")과 영어 흔한 말("it", "no", "on")은
  잡음 구간 환각이므로 지웁니다. (대문자 IT·US·OCI 같은 표기는 그대로)
· "1, 2, 2 2, 3" 처럼 한 자리 숫자만 늘어놓은 인식도 지웁니다.
  (+12%, 2만 2천, 120일선 같은 실제 표기는 그대로)
· 영상에서 딱 한 번만 나온 영문("QUES")은 환각으로 보고 지웁니다.
  (AI·GS·LNG 같은 3글자 이하, 알려진 표기, 대본에 있는 말, 두 번 이상
   나온 말은 그대로 둡니다)
· 대본으로 교정한 글자도 따옴표·특수문자를 걸러냅니다.
· +9% / -13% / 3.7% 같은 숫자 표기는 그대로 둡니다.
· 0.2초 미만 클립은 만들지 않습니다. (편집에도 못 쓰고 "..." 자막만 붙습니다)

* 자막 인식 속도
   - "빠른 자막 (짧은 클립 묶어서 인식)" 이 기본으로 켜져 있습니다.
     Whisper 는 클립이 2초든 30초든 항상 30초짜리로 계산합니다. 컷편집한
     클립은 대개 2~4초라서 계산의 대부분이 빈 공간에 버려집니다.
     그래서 짧은 클립을 30초 한 판에 몰아 넣고 한 번에 인식합니다.
     클립 8개가 한 판에 들어가면 그만큼(5~8배) 빨라집니다.
     · 클립 사이에는 무음을 넣고, 인식된 단어의 시각으로 어느 클립 말인지
       되돌립니다. 클립 경계는 원래대로 그대로 유지됩니다.
     · 소리는 분명히 있는데 한 마디도 못 건진 클립은 그 클립만 따로 다시
       인식합니다. (묶다가 놓치는 일이 없게)
     · 8초가 넘는 긴 클립은 묶지 않고 예전처럼 혼자 인식합니다.
     · 인식 내용이 이상해 보이면 이 체크를 끄세요. 예전 방식으로 돌아갑니다.
   - 인식은 CPU로 합니다. (GPU는 카드에 따라 오히려 느려서 쓰지 않습니다)
   - ★ 제일 큰 요인은 '클립 개수'입니다. Whisper 는 클립 하나마다 30초 한 판을
     계산하므로, 같은 영상이라도 클립이 2배로 쪼개지면 2배 느려집니다.
     클립이 많고 짧으면 실행 로그에 안내가 뜹니다. 그때는 '최소 무음 길이'를
     0.5~0.7초로 올리세요. 클립이 줄어 더 빠르고, 앞뒤 문맥이 살아나 자막도
     더 정확해집니다.
   - 오디오는 영상당 한 번만 뽑습니다. 예전에는 클립 하나마다 ffmpeg를 다시
     돌려서, 클립이 100개면 그만큼 시간이 더 걸렸습니다.
   - 실행 로그 끝에 "클립별 인식 완료 (N개) · 3.2분 · CPU int8 · 22판으로 묶음"
     처럼 걸린 시간이 표시됩니다.

* 대본을 넣으면 정확도가 올라갑니다.
  대본 입력칸에 붙여넣거나 .txt 파일을 불러오면, 인식 결과를 대본과 대조해
  오탈자를 고칩니다. (대본에 없는 애드립은 인식된 그대로 둡니다.)
  실행 로그에 "대본 참고 철자 교정 N개 적용" 이 표시됩니다.


■ 자료화면 (영상·이미지 자동 삽입)
----------------------------------------
"추가 파일" 에서 "파일 여러 개 선택" 으로 영상·이미지를 고르면
다운로드(저장) 시간 순으로 자동 정렬되어 배치됩니다.
 - 파일에 마우스를 올리면 어떤 이미지인지 미리보기가 뜹니다.
 - 파일마다 체크박스로 배경제거를 개별 선택할 수 있습니다.
   ★ 배경제거는 프로그램이 직접 처리해서 투명 PNG(흰색 발광 테두리 포함)로
     넣습니다. 캡컷에서 버튼을 누르지 않아도 처음부터 제대로 보입니다.
     - 처음 한 번은 배경제거 모델(176MB)을 자동으로 내려받습니다.
     - 만들어진 PNG는 outputs\cutouts 폴더에 보관됩니다. 이 폴더를 지우면
       캡컷에서 이미지가 안 보이니, 편집이 끝날 때까지 두세요.
     - 영상 파일의 배경제거는 캡컷에서 직접 켜주세요.
       (캡컷 배경제거는 캡컷이 계산한 마스크가 있어야 해서, 프로그램이 켜두기만
        하면 검은 화면이 됩니다. 그래서 이미지는 아예 미리 지워서 넣습니다)
 - 크기·위치를 통일해서 넣습니다 (캡컷 화면에 표시되는 값 기준).
     · 이미지 : 크기 79 / X 0 / Y -892
     · 영상   : 크기 87 / X 0 / Y -1022
 - "모든 자료화면에 랜덤 효과" 는 기본으로 켜져 있고, 자료화면 하나하나에
   빠짐없이 등장 효과가 들어갑니다. (몇 초마다가 아니라 전부)
   "선택 파일로만 새 프로젝트" 로 만들 때도 똑같이 전부 들어갑니다.
   바로 앞 클립과 같은 효과는 나오지 않게 골라 넣습니다.
   효과 길이 기본값은 0.4초입니다.
   메인 컷편집 영상에는 효과가 들어가지 않습니다.
 - "이미지 1장 길이" 기본값은 2초입니다. (영상 자료는 원본 길이 그대로)

 · 통합: 영상 경로를 넣고 "▶ draft 생성" 을 누르면 컷편집 영상 뒤에 이어붙습니다.
 · 자료만 (영상 없이 자료 파일만):
     1) 맨 위 영상 파일 경로는 비워둡니다.
     2) "📁 파일 여러 개 선택" 으로 자료 파일을 고릅니다.
     3) 그 옆 초록색 "🎬 자료만으로 draft 생성" 을 누릅니다.
   ※ 영상 경로가 비어 있으면 아래 "▶ draft 생성" 을 눌러도 자동으로 자료만
      모드로 만듭니다. (파일을 고르면 버튼 이름이 "🎬 자료 N개로 draft 생성"
      으로 바뀝니다)
   배경제거 · 랜덤 효과 · 크기/위치 통일 · 제목 · 날짜가 컷편집 모드와 똑같이
   적용됩니다. (자막은 말소리가 없으니 만들지 않습니다)

■ 문제 해결
----------------------------------------
· 설치가 실패하면: 인터넷/방화벽 문제일 수 있습니다. 다른 네트워크에서
  "설치및실행.bat" 을 한 번만 실행하면 runtime\ 이 만들어져 이후엔 오프라인도 됩니다.
· 실행 중 오류가 나면 이 폴더에 error_log.txt 가 생깁니다.
· "Cannot read properties of null" 같은 오류가 뜨면 화면(index.html)이 옛날
  것입니다. 브라우저에서 Ctrl+F5 로 새로고침하세요.
  로그 첫 줄의 "CapCut Agent 준비 완료 (화면 2026-08-11)" 날짜로 확인할 수
  있습니다. 날짜가 안 보이면 예전 화면입니다.
· 다시 처음부터 설치하고 싶으면: runtime\ 폴더를 지우고 다시 실행하세요.
· 자막 인식은 클립 수만큼 시간이 걸립니다. 진행 상황이 로그에 표시됩니다.
