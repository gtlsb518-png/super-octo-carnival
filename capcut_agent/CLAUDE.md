# CapCut Agent — 작업 메모

## 자막 인식 방식 (고정 — 절대 바꾸지 말 것)

자막 인식은 **"클립마다 그 클립 오디오로만 따로 인식"** 방식을 쓴다.
사용자가 "무조건 영상 위에 그 클립 말 그대로 자막이 있어야 한다"고 요청 (2026-09).
→ 자막이 옆 클립으로 밀리거나 건너뛰는 일이 원천적으로 없어야 함.

- 구현: `transcribe_all_clips` → `load_audio_16k`(오디오 **한 번만** 메모리 로드) 후
  각 클립을 `transcribe_clip_words(video, ks, ke, script, audio)` 로 **그 구간만 잘라 인식**.
- **속도 핵심**: 클립마다 ffmpeg 를 다시 돌리지 않고 메모리 배열에서 슬라이스한다.
  예전 느림의 원인이 '클립마다 ffmpeg'였음. 이걸 없애서 정확 + 빠름 둘 다 잡는다.
- **전체를 한 번에 인식(whole-audio)해서 단어를 클립에 분배하는 방식으로 되돌리지 말 것**
  — 경계에서 자막이 밀리거나 건너뛰어서 사용자가 싫어함.
- 오디오 로드 실패 시에만 클립별 ffmpeg 로 자동 폴백(transcribe_clip_words 안에 있음).

## 크래시 방지 (절대 되돌리지 말 것)

- 모델 로드는 **GPU(float16) 우선 → 실패 시 CPU `compute_type="auto"`**.
- CPU에서 `compute_type="int8"`을 강제하면 그 명령을 지원 안 하는 CPU에서 프로그램이 통째로 꺼진다(Illegal instruction, 파이썬 try/except로 못 잡음).

## 자막 끊기(청킹) 우선순위

- **문장/어미 기준 끊기가 먼저**, 글자 수 제한은 그 다음. (사용자 요청)
- 종결어미(-야/-어/-지/-거야/-잖아 …)로 문장이 끝나고 뒤에 말이 더 있으면
  글자 수와 무관하게 그 자리에서 먼저 끊는다 (`_is_final_ending`).
  단 연결어미(-는지/-면서/-니까 …)와 의존명사(거야/중이야 …)는 문장 끝이 아님 → 제외.
- 문장으로 끝난 조각의 끝말을 다음 조각으로 끌어오지 않는다(`_rebalance_tail` 가드).

## 영상 클립 하나 = 자막 클립 하나 (고정)

사용자 요청: "영상 클립 하나당 자막 클립 하나 나오게 해야된다고
긴 영상에 중복 단어 있으면 하나만 나오게 해야하고" (2026-09).

- `subtitle_chunks_for_timeline` 은 클립마다 자막을 **딱 하나만** 만든다.
  말이 길면 시간으로 쪼개지 않고 **줄바꿈(`\n`, 최대 `MAX_SUB_LINES`줄)** 으로만 나눈다.
  → 예전처럼 0.2~0.3초짜리 조각이 우수수 지나가며 문장이 다 쪼개지지 않는다.
- 줄바꿈 자리는 `chunk_words_korean` 이 잡아준 어미/어절 자리를 그대로 쓴다.
- 자막 시작은 클립 시작. 단 0.4초(`LEAD_SNAP_US`) 넘게 늦게 말하면 그 시각부터.
  자막 끝은 항상 클립 끝.
- 한 클립 안에서 같은 말을 반복(더듬기·다시 말하기)하면 `dedupe_clip_words` 로
  한 번만 남긴다. 똑같이 반복되면 띄어쓰기가 나은 쪽, 발음이 뭉개진 반복이면
  다시 말한 쪽을 남긴다. 붙어 있는 반복만 지우고 문장에 흩어진 같은 단어는 둔다.
- 자막은 영상 클립 경계를 넘지 않는다.

## 자막 후처리 정책

- 자막 후처리(중복 합치기·끝음절 흡수 등)는 **넣지 않는다** — 사용자가 원치 않음. `subtitle_chunks_for_timeline`은 인식 결과를 그대로 반환.
- 숫자/영어 잡음 필터(`clean_recognized_text`, `_is_number_babble`, `is_hallucinated_line` 등)는 유지 — `I`, `it`, `2 2 3` 같은 헛것 제거에 필요.

## 테스트

- `python3 tests/자막_기준_테스트.py` — 자막 끊기 gold 테스트. 변경 후 반드시 통과 확인.
- 이 환경(샌드박스)엔 **ffmpeg·Whisper 모델·GPU 가 없어** 실제 인식은 못 돌린다. 순수 파이썬 로직(분배·필터·청킹)만 여기서 검증 가능.
