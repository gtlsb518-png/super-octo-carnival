무음 감지 설정
컷 여유   + 면 더 남기고(말 안 씹힘), − 면 더 깎습니다(타이트)
※ 노이즈 임계값 "자동"이면 영상마다 방 소음을 재서 알맞은 값을 고릅니다.
※ 기본값: 노이즈 자동 / 최소 무음 0.3s / 앞 +10ms / 뒤 -10ms
※ 말이 씹히면 "앞 여유"를 0 → +100ms 쪽으로 올리세요.
※ 엔지컷을 남겨서 직접 고르실 거면 "짧은 클립 버리기"는 꺼두세요.
같은 말이 연달아 2번 이상 나올 때만 동작합니다. 긴 테이크는 여러 개라도 전부 남겨서 직접 고르실 수 있게 합니다. (자막 켜야 동작 — 말 내용으로 판단)
