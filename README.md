# 바이낸스 선물 자동매매 봇

UT Bot + EMA 크로스 신호 기반 바이낸스 USDT-M 선물 자동매매 프로그램 (tkinter GUI).

## 실행 방법

```bash
python 9_main.py
```

필요한 라이브러리(pandas, numpy, requests, openpyxl)는 실행 시 자동 설치됩니다.
tkinter가 없는 리눅스에서는 `sudo apt-get install python3-tk`로 설치하세요.

## 설정

`1_config.py`에서 수정:

- `API_KEY` / `API_SECRET`: 바이낸스 API 키 (현재 테스트넷 키)
- `TESTNET`: `True`=테스트넷(데모), `False`=메인넷(실거래)

첫 실행 후에는 `settings.json`이 생성되어 그 값이 우선 적용됩니다.

⚠️ 메인넷 키를 사용할 경우 절대 저장소에 커밋하지 마세요.

## 🐋 고래 추종 봇 + 🏆 리더보드 트레이더 추적 (`whale_bot.py`)

실시간으로 큰손(고래)의 시장가 체결을 감지해 자동 진입·청산하고, 동시에 바이낸스
리더보드 상위 트레이더의 포지션·성과·승률을 보여주는 단독 실행형 프로그램입니다.

```bash
python whale_bot.py     # 더블클릭 가능 (websocket-client 자동 설치)
```

### ① 고래 추종 자동매매 (실시간 대형체결)

- **데이터**: 바이낸스 선물 실시간 체결 스트림(`aggTrade`, 항상 메인넷)을 WebSocket으로 구독
- **고래 감지**: 단일 체결금액 ≥ `고래 기준금액`(기본 $500,000)인 시장가 체결만 '고래'로 집계
- **진입**: 최근 `집계 창`(기본 10초) 동안 고래 순매수 − 순매도 = 순흐름
  - 순흐름 ≥ `진입 임계금액`(기본 $1,000,000) → **롱**
  - 순흐름 ≤ −임계금액 → **숏** (숏 허용 시)
- **청산 (2중)**:
  1. 진입 즉시 거래소에 TP(익절)/SL(손절) 주문 등록 → 프로그램이 꺼져도 거래소가 청산
  2. 보유 중 고래 흐름이 반대로 강하게 뒤집히면 즉시 시장가 청산(`고래 반대신호 시 청산`)
- **🪙 코인별 개별 설정**: `[코인별 개별 설정]` 버튼에서 코인마다 고래기준·진입임계·진입금·
  레버리지·TP·SL을 따로 지정(비우면 공통값 사용). BTC는 크게, 알트는 작게 잡을 수 있습니다.
- **안전장치**: 기본 테스트넷 모드, 청산 후 재진입 쿨다운, 코인당 1포지션, 최대 포지션 수 제한

### ② 리더보드 트레이더 추적 (실명 고래)

- `[🏆 리더보드 트레이더]` 탭에서 바이낸스 선물 리더보드 상위 트레이더를 실시간 조회:
  - **어떻게 진입했는지**: 현재 공개 포지션(코인·방향·진입가·레버리지·ROE·평가손익)을 트리로 펼쳐 확인
  - **성과**: ROI / 누적손익 (Binance 제공)
  - **승률**: Binance가 승률을 제공하지 않으므로, **이 프로그램이 각 트레이더의 포지션
    청산을 관찰해 직접 집계**합니다(프로그램이 지켜본 기간만큼 누적, 마지막 평가손익 부호로 승/패 판정).
- 기간(DAILY/WEEKLY/MONTHLY/ALL)·정렬(ROI/PNL)·추적 인원·갱신주기를 조절할 수 있습니다.
- 승률 누적은 `whale_leaderboard_stats.json`에 저장되어 재실행 시 이어집니다.

### 저장 파일

- 설정: `whale_settings.json` (API 키 없으면 `1_config.py`에서 가져옴)
- 거래 기록: `whale_trades.csv` · 리더보드 관찰 승률: `whale_leaderboard_stats.json`

> 💡 임계금액이 낮으면 잦은 진입, 높으면 신호가 드물어집니다. 코인별 거래량에 맞춰 조절하세요.
> 🌐 체결 스트림·리더보드는 메인넷 바이낸스에 접속합니다. WebSocket/아웃바운드가 막힌
> 환경이나 지역 제한(리더보드 API 403/451)에서는 연결이 안 되니 일반 네트워크에서 실행하세요.

## 매매 로직 요약

- **진입**: UT Bot 상태 + EMA(34/55) 크로스 AND 조건, 코인당 LONG/SHORT 봇 각 1개 (기본 1시간봉)
- **익절**: ADX(기간 10, 1시간봉) 기반 동적 TP — 추세장(ADX≥21) 3.0% / 횡보장 2.0%
- **손절/스위칭**: 고정 손절 없음 — 보유 중 역신호(UT+EMA) 발생 시 청산 후 즉시 반대 방향 진입 (AUTO 스위칭이 유일한 손절 수단)
- 차트 데이터는 항상 메인넷 시세, 주문은 테스트넷/메인넷 선택
- 거래 기록은 `trade_history.xlsx`(코인별 시트), 통계는 `bot_stats.json`에 저장
