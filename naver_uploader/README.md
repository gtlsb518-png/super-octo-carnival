# 네이버 스마트스토어 자동 상품등록 프로그램

엑셀에 상품 정보를 적어 넣으면, 크롬 브라우저를 자동으로 조작해서
**네이버 스마트스토어 상품등록 페이지의 입력칸들을 자동으로 채워 주는** 프로그램입니다.

```
엑셀 작성 → 프로그램 실행 → 크롬이 열리고 자동 입력 → (선택) 자동 저장
```

## 1. 설치 (처음 한 번만)

1. [파이썬](https://www.python.org/downloads/) 설치 (설치 시 **Add Python to PATH** 체크!)
2. 크롬 브라우저 설치 (이미 있으면 생략)
3. 이 폴더(`naver_uploader`)에서 명령 프롬프트를 열고:

```
pip install -r requirements.txt
```

## 2. 사용 방법

### ① 엑셀 양식 만들기

```
python make_template.py
```

`상품등록_양식.xlsx` 파일이 생깁니다. **상품목록** 시트에 한 줄에 상품 하나씩 채워 넣으세요.
(자세한 작성법은 엑셀 안의 **작성방법** 시트 참고)

| 열 | 필수 | 설명 |
|---|---|---|
| 카테고리 | | 카테고리 검색어 (예: `패션잡화>모자>버킷햇` 또는 `버킷햇`). 검색 첫 결과가 선택됨 |
| 상품명 | ✅ | 스마트스토어에 표시될 상품명 |
| 판매가 | ✅ | 숫자만 (예: `19900`) |
| 재고수량 | ✅ | 숫자만 (예: `100`) |
| 상세설명 | | 상세페이지에 들어갈 글 (셀 안 줄바꿈 Alt+Enter 가능) |
| 대표이미지 | | 내 컴퓨터의 이미지 파일 전체 경로 (예: `C:\상품사진\a.jpg`) |
| 추가이미지 | | 여러 장이면 쉼표(,)로 구분 |
| 배송비 | | `0` 또는 빈칸 = 무료배송, 숫자 = 유료배송 금액 |

### ② 실행

**GUI로 실행 (추천):**

```
python gui.py
```

엑셀 파일 선택 → [시작] 클릭.

**명령행으로 실행:**

```
python uploader.py 상품등록_양식.xlsx
```

### ③ 로그인 (처음 한 번만)

크롬 창이 열리고 로그인 화면이 나오면 **직접 네이버 로그인**을 해주세요.
로그인 정보는 `chrome_profile` 폴더에 저장되어 다음부터는 자동으로 유지됩니다.
(자동 로그인 입력은 네이버가 봇으로 감지해서 막는 경우가 많아, 첫 로그인만 수동으로 하는 방식입니다)

### ④ 저장 방식

- 기본값은 **자동 저장 꺼짐**: 입력만 자동으로 해두고, 사람이 화면을 확인한 뒤
  직접 [저장하기]를 누릅니다. 누르고 나서 확인 창의 확인을 누르면 다음 상품으로 넘어갑니다.
- GUI의 **자동 저장** 체크(또는 `config.py`의 `AUTO_SUBMIT = True`)를 켜면
  [저장하기] 클릭까지 자동으로 합니다. **처음 몇 번은 꺼둔 상태로 결과를 확인한 뒤 켜는 것을 권장합니다.**

각 상품의 성공/실패 결과는 엑셀의 **업로드결과** 열에 자동 기록됩니다.

## 3. 설정 변경

`config.py` 파일을 메모장으로 열어 수정:

- `AUTO_SUBMIT` : 자동 저장 여부
- `ACTION_DELAY` : 입력 사이 대기 시간 (컴퓨터가 느리면 늘리기)
- `WAIT_TIMEOUT` : 화면 요소 대기 최대 시간

## 4. 자주 묻는 문제

**"○○ 입력칸을 찾지 못했습니다" 오류가 나요.**
네이버가 판매자센터 화면을 개편하면 입력칸 위치가 바뀔 수 있습니다.
`uploader.py` 위쪽의 `SELECTORS` 에서 해당 항목의 셀렉터만 고치면 됩니다.
(크롬에서 F12 → 요소 선택 도구로 해당 입력칸의 placeholder나 구조를 확인)

**입력이 중간에 씹혀요 / 너무 빨라요.**
`config.py` 의 `ACTION_DELAY` 를 `1.5` 정도로 늘려보세요.

**엑셀에 결과가 안 적혀요.**
실행 중에는 엑셀 파일을 닫아두세요. 열려 있으면 기록할 수 없습니다.

**옵션(색상/사이즈)도 자동으로 넣고 싶어요.**
옵션 조합 입력은 화면 구조가 복잡해서 현재 지원하지 않습니다.
등록 후 스마트스토어에서 직접 추가해 주세요.

## 5. 주의사항

- 이 프로그램은 사람이 하는 입력을 대신해 주는 도구입니다.
  **너무 짧은 간격으로 대량 등록하면 네이버가 비정상 활동으로 판단할 수 있으니**,
  `BETWEEN_PRODUCTS_DELAY` 를 충분히 두고 본인 계정 책임 하에 사용하세요.
- 자동 저장을 켜기 전에 반드시 몇 개는 수동 저장 모드로 결과를 확인하세요.
- 대량 등록이 목적이라면 스마트스토어 판매자센터의 공식 **엑셀 일괄등록**
  (상품관리 → 상품 일괄등록) 기능도 함께 검토해 보세요.
