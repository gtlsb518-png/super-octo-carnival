# 🎬 유튜브 / 틱톡 자동 업로드 프로그램

제목·상세정보·태그·영상파일·썸네일을 입력해두고 **버튼 하나만 누르면**
유튜브와 틱톡에 각각 자동으로 올려주는 프로그램입니다.

```
┌─────────────────────────────────────────────────┐
│  1단계 · 브라우저 준비                            │
│  [① 로그인 정보 가져오기] [② 크롬 열기] [③ 화면 진단] │
├──────────────────────┬──────────────────────────┤
│       유튜브          │          틱톡             │
│  제목                 │   제목                    │
│  상세정보             │   상세정보                 │
│  태그                 │   태그                    │
│  고정 댓글            │   영상 파일                │
│  영상 파일            │   커버 이미지              │
│  썸네일               │   공개 설정                │
│  예약 날짜·시간        │   예약 날짜·시간           │
│  [▶ 유튜브 업로드]     │   [▶ 틱톡 업로드]          │
├──────────────────────┴──────────────────────────┤
│  진행 상황 (로그)                                 │
└─────────────────────────────────────────────────┘
```

---

## 실행 방법

```bash
python up_main.py
```

필요한 라이브러리(playwright)는 **처음 실행할 때 자동으로 설치**됩니다.
크롬은 직접 설치되어 있어야 합니다.

---

## ⚠️ "로그인 안 해도 되게" 하는 방법 (중요)

**이미 켜져 있는 크롬 창에 그냥 붙는 것은 크롬 보안상 불가능합니다.**
크롬은 `--remote-debugging-port` 옵션으로 켜진 창만 외부 프로그램이 제어할 수 있습니다.
(아무 창이나 제어할 수 있으면 악성코드가 남의 계정을 다 털 수 있기 때문입니다.)

그래서 이 프로그램은 **로그인 정보(쿠키)를 그대로 가져오는 방식**을 씁니다.
결과는 똑같습니다 — 다시 로그인할 필요가 없습니다.

### 최초 1회만 하면 되는 설정

| 순서 | 할 일 |
|------|-------|
| 1 | **크롬을 완전히 종료** (트레이/작업표시줄까지 전부) |
| 2 | `[① 크롬 로그인 정보 가져오기]` 클릭 |
| 3 | `[② 업로드용 크롬 열기]` 클릭 |
| 4 | 열린 창에서 유튜브·틱톡이 로그인 되어 있는지 확인 |

> ①이 실패하거나 로그인이 안 넘어왔다면, ②로 연 창에서 **한 번만 직접 로그인**하세요.
> 그 창의 로그인 상태는 `uploader/chrome_profile` 폴더에 계속 저장되므로
> 다음부터는 로그인이 필요 없습니다.

### 다음부터는

1. `[② 업로드용 크롬 열기]` 클릭 (이미 켜져 있으면 생략)
2. 내용 입력 → `[유튜브 업로드]` 또는 `[틱톡 업로드]` 클릭

## 업로드 버튼을 누르면 일어나는 일

### 유튜브 (버튼 1번 = 10단계 자동 진행)

```
1. 영상 업로드 + 제목/설명/태그/썸네일 입력
2. '일부공개'로 먼저 게시          ← 댓글을 달려면 영상이 올라가 있어야 함
3. 영상 페이지로 이동 → 고정 댓글 작성
4. 그 댓글을 '고정'
5. 스튜디오로 돌아가 '예약'으로 변경 (지정한 날짜·시간)
```

> **안전장치** — 3~5단계가 실패해도 영상은 **일부공개 상태로 남습니다.**
> 실수로 전체공개 되는 일은 없습니다. 로그에 어디서 멈췄는지 찍히니
> 그 부분만 직접 마무리하면 됩니다.

### 틱톡

```
1. 영상 업로드 + 캡션(제목+설명+해시태그) 입력
2. 커버 이미지 지정
3. 공개 범위 설정
4. '예약 게시' 켜고 날짜·시간 지정
5. 게시
```

> **안전장치** — 4단계(예약 설정)가 실패하면 **게시 버튼을 누르지 않고 중단합니다.**
> 예약하려던 영상이 지금 바로 올라가는 사고를 막기 위한 것입니다.

---

## 예약 시간 입력

| 칸 | 형식 | 예시 |
|----|------|------|
| 날짜 | `YYYY-MM-DD` | `2026-09-20` |
| 시간 | `HH:MM` (24시간제) | `09:00`, `21:30` |

- **예약 게시** 체크를 끄면 예약 없이 진행됩니다.
  (유튜브는 일부공개 그대로, 틱톡은 바로 게시)
- `+1일` 버튼으로 날짜를 하루씩 미룰 수 있습니다.
- 처음 실행하면 **내일 09:00** 으로 채워져 있습니다.
- **틱톡 제약**: 최소 20분 뒤 ~ 최대 10일 뒤, **5분 단위**만 가능합니다.
  (`09:07` 을 넣으면 `09:05` 로 자동 보정됩니다)
- 잘못된 형식이나 지나간 시간은 **업로드를 시작하기 전에** 걸러냅니다.

---

## 입력 항목 설명

| 항목 | 유튜브 | 틱톡 |
|------|--------|------|
| **제목** | 영상 제목 | 캡션 첫 줄로 들어감 |
| **상세정보** | 설명란 | 캡션 본문으로 들어감 |
| **태그** | 태그란 (쉼표로 구분) | `#해시태그`로 자동 변환되어 캡션에 붙음 |
| **영상 파일** | mp4 등 | mp4 등 |
| **썸네일 / 커버** | 썸네일 이미지 | 커버 이미지 |
| **고정 댓글** | 게시 후 자동으로 달고 고정 (비우면 건너뜀) | — |
| **공개 설정** | 자동 (일부공개 → 예약) | 전체공개 / 친구만 / 나만보기 |
| **예약 날짜·시간** | 예약 전환 시각 | 예약 게시 시각 |

입력한 내용은 `uploader_settings.json` 에 자동 저장되어,
프로그램을 껐다 켜도 그대로 남아 있습니다.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `up_main.py` | **실행 파일** (라이브러리 자동 설치 후 GUI 실행) |
| `up_gui.py` | 화면 (유튜브/틱톡 섹션, 버튼, 로그) |
| `up_browser.py` | 크롬 연결·실행, 로그인 정보 복사 |
| `up_youtube.py` | 유튜브 스튜디오 업로드 자동화 |
| `up_tiktok.py` | 틱톡 스튜디오 업로드 자동화 |
| `up_check.py` | **화면 진단 도구** (업로드가 멈출 때 원인 찾기) |

## 자주 나는 문제

| 증상 | 해결 |
|------|------|
| `크롬이 디버그 모드로 뜨지 않았습니다` | 켜져 있는 크롬 창을 **전부** 닫고 ② 다시 클릭 |
| `구글 로그인이 안 되어 있습니다` | ②로 연 창에서 유튜브에 직접 로그인 |
| `틱톡 로그인이 안 되어 있습니다` | ②로 연 창에서 틱톡에 직접 로그인 |
| `요소를 찾지 못했습니다` | 유튜브/틱톡이 화면을 바꾼 경우입니다. 로그에 찍힌 단계 번호를 알려주시면 선택자를 고쳐드립니다 |
| 커버(틱톡) 설정 실패 | 틱톡 커버 편집 UI는 변경이 잦습니다. 실패해도 업로드는 그대로 진행됩니다 |
| `날짜 형식을 유튜브가 받아들이지 않았습니다` | 스튜디오 예약창에 **실제로 보이는 날짜 표기**를 확인한 뒤, `up_youtube.py` 맨 위 `DATE_FORMATS` 에 그 형식을 추가하세요 |
| `시간 형식을 유튜브가...` | 같은 방법으로 `TIME_FORMATS` 에 추가 |
| `'예약 게시' 스위치를 찾지 못했습니다` | 틱톡 화면이 바뀐 경우입니다. **영상은 게시되지 않았습니다** |
| `댓글 입력창을 찾지 못했습니다` | 영상 댓글이 꺼져 있거나 아직 처리 중입니다. 잠시 뒤 직접 달아주세요 |
| 예약 시간이 이미 지났습니다 | 날짜/시간칸을 확인하세요 (24시간제) |

> 업로드 중에는 자동으로 열린 크롬 탭을 **건드리지 마세요.** 클릭이 어긋납니다.
> 업로드가 끝나도 결과 확인을 위해 탭은 자동으로 닫지 않습니다.

## 업로드가 중간에 멈췄을 때 — 화면 진단

유튜브·틱톡은 화면을 수시로 바꿉니다. 어느 날 갑자기 특정 단계에서 멈추면
**추측하지 말고 진단 도구를 돌리세요.**

1. `[② 업로드용 크롬 열기]` 로 연 창에서 **멈춘 그 화면을 그대로 띄워둡니다**
   (예: 틱톡 업로드 화면에서 '예약 게시'를 켠 상태)
2. `[③ 화면 진단하기]` 클릭 (또는 `python up_check.py`)
3. `진단결과` 폴더에 생긴 파일 3개를 전달

| 파일 | 내용 |
|------|------|
| `요소_*.txt` | 어떤 선택자가 먹고 안 먹는지 + 화면에 실제로 있는 요소 목록 |
| `화면_*.png` | 그 순간 화면 사진 |
| `전체_*.html` | 페이지 전체 HTML (정확한 수정용) |

`요소_*.txt` 는 이렇게 생겼습니다:

```
  ✘ 예약 게시 스위치
    ✘   0개  [data-e2e='schedule_switch']
    ✘   0개  div[class*='schedule'] input[type='checkbox']
    ...

[ 화면에 있는 요소들 (선택자 고칠 때 참고) ]
  <span class="lbl-x">   "예약 게시하기"
```

→ `✘` 가 뜬 항목이 원인입니다. 바로 아래 후보 목록을 보고
   `up_tiktok.py` / `up_youtube.py` 맨 위 `SEL` 에서 그 항목만 고치면 됩니다.
   (선택자가 전부 한곳에 모여 있어 코드를 뒤질 필요가 없습니다)

  멈출 수 있습니다. 그럴 땐 로그의 `[n/8]` 단계 번호를 확인하면 어디가 막혔는지 바로 알 수 있습니다.
